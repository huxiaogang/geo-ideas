# 平面几何「解题思想方法」训练站 — 产品与技术方案（v1.1 定稿）

> 目标用户：初中数学竞赛生（联赛 / 自招 / 华杯·希望杯体系），已有一定基础，**缺的不是题量，是"看到图形该想什么"的检索能力**。
> 核心命题：把"解题直觉"拆成**可检索、可训练、可复现**的四层知识 + 一套诊断式导航。

## 已确认的三项决策

| 项 | 决定 | 对方案的约束 |
|---|---|---|
| 难度带 | **培优 → 联赛 → 自招 三层并存** | 每张卡片/例题必须打 `tier` 标签；同一模型出 2–3 档变式而不是换题 |
| 技术形态 | **零依赖静态站**，双击 `index.html` 即开，可丢任意静态托管 | 禁止构建步骤与 npm 依赖；KaTeX 与字体本地化；`file://` 协议下必须能跑（不用 fetch 读 JSON，内容以 JS 模块文件提供） |
| 交付范围 | **P0 + P1 + P2 全做**（含训练闭环），P3 打磨择要 | 一次交付可学、可练、可复现的完整闭环 |

## 一、先诊断：为什么市面上的资源低效

| 现状 | 真实痛点 |
|---|---|
| 题库类（菁优、作业帮） | 给答案不给**决策过程**：不知道"为什么第一步想作中线" |
| 教辅《几何辅助线秘籍》类 | 方法按**章节**平铺，学生脑子里没有"条件 → 方法"的反查索引 |
| 视频课 | 线性播放，无法按"我卡在哪一步"跳转；看完就忘 |
| 刷题群 / 错题本 | 记的是**整题**，不是**模型**，迁移不了；同错三次仍错 |

**结论：竞赛几何的低效来源于"检索失败"，不是"知识缺失"。**
一道题卡住，90% 是这五种情况之一：

1. 没看出图里的**已知模型**（手拉手、半角、一线三等角…）
2. 知道模型，但**不会补辅助线**把它造出来
3. 辅助线作对了，**目标链条**（要证什么 → 中间需要什么）断掉
4. 全对但**算不动**（比例式、三角、坐标算错）
5. 会做但**慢**（无识别速度，考场上 20 分钟换 40 分钟）

所以网站的每一个功能都必须对准这五条之一，其余一律不做。

## 二、效率杠杆：本站凭什么"更高效"

1. **反查索引（Condition → Method）**
   不按"章节"组织，按**题干特征**组织：`出现中点`、`出现角平分线`、`两线段相等`、`四点共圆`、`求最值`… 输入条件，输出候选方法与命中理由。→ 直接治 ①③

2. **模型卡（Pattern Card）：图形是主键**
   一张卡 = 一个图式 + 识别信号 + 辅助线动作 + 结论 + 易错 + 关联题。
   正面只看图（**主动回忆**），背面才是套路。→ 治 ①②

3. **阶梯提示（Hint Ladder）**：观察 → 联想 → 关键构造 → 主链 → 完整解
   学生自己控制"看到第几层"，绝不一次给答案。→ 治 ②③，且保护思考

4. **决策注解（Decision Note）**
   每个例题必写："当时为什么先试这个？为什么放弃另一个？"
   这是全网最缺、也最值钱的部分。→ 治 ①

5. **一法多题 / 一题多解 的双向链接**
   方法卡 ↔ 题目卡 多对多；同一方法的 3 道不同外观题并排，逼出**抽象**。→ 治迁移

6. **可拖动图形的不变量**
   手拉手旋转 60°时 `BM = CN` 恒成立——拖动看出"变的量与不变的量"，比背结论强 10 倍。→ 治 ②，且建立"变换"直觉

7. **错因四分类 + 间隔重复**
   错题只记"卡在哪个模型 / 哪种错因（没想到、想到不会用、算错、图看错）"，一周后按模型复现。→ 治 ⑤

8. **5 分钟微训练**
   限时识别题（只看图说方法，不写过程），专门练速度。→ 治 ⑤

## 三、知识体系：四层，不做平铺

```
L0 分档（每条内容都带 tier）  培优 T1 / 联赛 T2 / 自招 T3
         ↓ 支撑
L1 思想（7 条）        化归 / 图形变换 / 构造补形 / 算两次 / 代数化 / 不变量与特殊化 / 对称对应
         ↓ 支撑
L2 方法（约 26 张）     全等构造、相似与比例、圆幂三定理、四点共圆判定、三角法、坐标向量复数、
                       面积法、梅氏塞瓦、反演、位似与螺旋相似、根轴…
         ↓ 落地
L3 模型·图式（约 40 张） 手拉手、半角、一线三等角、倍长中线、中位线、角平分线四定理、隐形圆、
                       托勒密、西姆松、费马点、阿氏圆、胡不归、婆罗摩笈多、鸡爪定理、欧拉线…
         ↓ 检验
L4 题（首发 40 道）      联赛中档 → 自招压轴，每题带阶梯提示 + 决策注解 + 变式
```

**同一条思想穿三档**，而不是三个互不相干的题库：

| 例：旋转 | T1 培优 | T2 联赛 | T3 自招 |
|---|---|---|---|
| 手拉手 | 两个共顶点等腰，证 `BM=CN` | 顶角不等 → 旋转相似 + 定角 | 三等腰/等角线推广，求点轨迹 |
| 半角 | 正方形内 45°，证 `EF=BE+DF` | 一般化到 60°/120°，求周长最值 | 与隐形圆/根轴结合 |

这样分层不会膨胀成三套体系：**每张卡片带 `tier`，例题按 `tier` 出变式**。

### 首批内容清单（P1 交付）

- **L1**：7 张思想卡（每张含 2 个"该思想失败时怎么办"）
- **L2**：12 张方法卡（先做高频：全等构造、相似比例、四点共圆判定、圆幂、梅氏塞瓦、面积法、三角法、坐标法、位似、旋转相似、反演入门、根轴）
- **L3**：20 张模型卡（手拉手、半角、一线三等角、倍长中线、中位线、角平分线四定理、等腰三线合一延伸、共圆四判定、圆幂三定理、托勒密、费马点、隐形圆、阿氏圆、胡不归、鸡爪、欧拉线、婆罗摩笈多、燕尾/面积比、弦切角、切线长）
- **L4**：16 道例题（每道 5 层提示 + 决策注解 + 2 个变式链接）
- **反查表**：约 18 个条件特征标签，覆盖上述全部卡片

**关键设计：卡片是"最小可迁移单元"。** 学生复习的是模型卡（30 秒一张），不是整道题（20 分钟一道）。

### 卡片字段规范（示例：模型卡）

```js
{
  id: "pat-hand-in-hand",
  title: "手拉手模型（共顶点等腰旋转）",
  level: "L3",
  tier: [1, 2, 3],                   // 三档都能讲，例题按时分层
  figure: "hand-in-hand",            // 几何引擎图 id
  signals: ["两等腰三角形共顶点", "顶角相等", "要证两线段相等"],
  trigger: "看到 AB=AC、AD=AE 且 ∠BAC=∠DAE → 立刻找 BM=CN、△ABM≌△ACN",
  action: "把两个等腰三角形看成同一旋转的两个像；连 BD、CE 造全等",
  conclusions: ["BM=CN", "∠BMC=∠BAC", "AP 平分 ∠BPD"],
  traps: ["顶角不等时只能得相似，不能得全等", "旋转中心必须共顶点"],
  relatedMethods: ["m-rotation-similarity", "m-congruence-construct"],
  problems: ["pr-0012", "pr-0031"]
}
```

## 四、功能与页面

| # | 页面 | 作用 | 关键交互 |
|---|---|---|---|
| 1 | **今日**（首页） | 20 分钟闭环：3 张模型卡回顾 + 1 道题 + 1 组限时识别 | 一键开始、进度环、连续天数、当前档位切换 |
| 2 | **解题罗盘** ⭐ | 反查索引：勾选题干特征 → 排序推荐方法/模型 | 标签多选、命中理由、点击直达卡片 |
| 3 | **方法地图** | L1→L2→L3 的关系图 | 缩放、按"我卡住的类型"高亮子图 |
| 4 | **模型库** | 卡片墙，正面只给图 | 翻卡、SRS 评级（会/模糊/不会）、按 tier 筛选 |
| 5 | **例题精讲** | 分栏解答 + 阶梯提示 | 逐层揭示、可拖图、决策注解折叠 |
| 6 | **训练场** | 限时识别 + 选做证明 | 计时、判分、错因四分类 |
| 7 | **错题图谱** | 按"模型 × 错因"热力图 | 定位薄弱模型、生成复现清单 |
| 8 | **搜索** | 全文 + 公式 + 标签 | `/` 唤起 |

**移动端优先**（竞赛生大量时间在手机上看题），桌面端双栏。
**全局档位开关** `T1 培优 / T2 联赛 / T3 自招`：影响今日计划、模型库默认筛选、罗盘推荐排序，内容本身不分家。

## 五、技术方案（零依赖静态站，双击可开）

选型理由：内容型站点 + 大量公式 + 手绘图，**不需要打包器**；离线可用（竞赛生常断网/在校），部署零成本（直接开 HTML 或丢 GitHub Pages）。

- **形态**：纯静态站，`ES modules` + hash 路由，**无构建、无 npm 依赖**
- **`file://` 硬约束**：双击打开时浏览器禁止 `fetch` 本地文件，所以**内容不用 JSON 而是 `.js` 模块**（`content/problems.js` 里 `export const problems = [...]`），用 `<script type="module">` 天然可加载；同理 KaTeX 不用 CDN，落盘到 `vendor/`
- **公式**：KaTeX 本地化（CSS + 字体 woff2 + JS），自写极简 Markdown（标题/列表/表格/`$..$`/`$$..$$`/代码/加粗）
- **图形**：自研迷你几何引擎 `geo.js`
  - 声明式点定义：`P('B')`、`rot(A, C, 60)`、`mid(A,B)`、`interLC(线,圆)`…
  - 自动渲染：线段/圆/弧/直角标记/等长刻线/角标/标签避让
  - **自由点可拖动**，派生点实时重算 → 支撑"不变量"教学
  - 图与卡片解耦：`figures/*.js` 导出图定义，卡片用 id 引用
- **数据**：`content/*.js`（idea / method / pattern / problem / tag），纯数据可增量编辑
- **持久化**：`localStorage`（SRS 状态、错题、打卡、笔记）；导入/导出 JSON 备份

> 备选：若后续要做账号/同步，再迁 Vite + React + Supabase；当前阶段不引入，避免复杂度吃掉内容产能。

## 七、风险与取舍

| 风险 | 处理 |
|---|---|
| 几何图画错（最致命） | 图用**坐标 + 断言**定义，渲染前校验共线/共圆/等长；关键图附"逆推核验"注释 |
| 内容产能不足 | 卡片最小化（一个信号一句话），先 20 张精品 > 200 张水卡 |
| 变成"又一个题库" | 强制字段：signals / trigger / decisionNote / traps，缺字段的内容不入库 |
| 学生只看不练 | 首页只有"今日"一个主入口，按 SRS 强制回顾 |
| 三层难度膨胀成三套体系 | 同卡片带 `tier` 数组，靠"变式"升档，不另起内容线 |

## 八、知识骨架：以陈祖维的思路为主线

> 说明：陈祖维的课程讲义不公开，这里把他几何教学的**公认特征**抽象成可操作的骨架（基本图形为纲、变换为生成器、圆的高级观点），是我们对其思路的重构，不是原讲义复刻。若你能提供他的课程目录/讲义，可按小节号逐一映射。

### 8.1 解题的四步定式（全站统一话术）

```
① 识图：这张图由哪些「基本图形」拼成？已有几个，缺几个？
② 生成：缺的那个，用哪种变换/构造把它造出来？（平移·旋转·翻折·位似·补形）
③ 落地：造出来后，用哪套工具算/证？（全等相似·三角·坐标复数·面积·圆幂）
④ 验算：结论在极端位置（退化、特殊点）是否仍成立？
```

**关键点：陈派几何的重心不在"技巧库"，而在"识图"——** 先把图形拆成基本图形的组合，辅助线就变成"补一个已知图形"的规定动作，而不是灵感。所以本站把「基本图形卡」放在最中心，方法卡是它的工具，思想卡是它的调度原则。

### 8.2 三层主干（陈派口径）

| 层 | 名称 | 内容 |
|---|---|---|
| 骨架 | **基本图形**（约 40 张） | 中点家族、角平分线家族、等腰/等边、共顶点旋转（手拉手）、半角、一线三等角、十字架、圆内接四边形、切线、四点共圆、位似与螺旋相似、完全四边形、调和结构 |
| 生成器 | **四大变换 + 补形** | 平移、旋转（含 60°/90°/定角）、翻折（对称）、位似；补形（补成平行四边形/正三角形/等腰梯形/圆） |
| 工具 | **论证与计算** | 全等与相似、比例与面积、圆幂三定理、三角法（正弦/余弦/面积）、坐标与复数、梅氏·塞瓦、根轴与反演 |

陈派的**分档**而不是分层：同一基本图形在初联、联赛二试、自招/CMO 三档各有深度的讲法（例如"圆内接四边形"：初联讲托勒密与四点共圆判定，联赛讲根轴与幂，自招讲调和与反演）。

### 8.3 首批内容清单（P1 交付）

- **思想卡 7 张**：化归、变换、补形、算两次、代数化、不变量与特殊化、对称对应
- **方法卡 12 张**：全等构造、相似与比例、四点共圆判定、圆幂三定理、面积法、三角法、坐标法、梅氏塞瓦、位似与螺旋相似、根轴、反演入门、调和入门
- **基本图形卡 20 张**：倍长中线、中位线、三线合一、角平分线四定理、手拉手、半角、一线三等角、十字架、共圆四判定、圆幂三定理、托勒密、费马点、隐形圆、阿氏圆、胡不归、鸡爪、欧拉线、婆罗摩笈多、面积比（燕尾/共角）、弦切角
- **例题 16 道**：每道 5 层阶梯提示 + 决策注解 + 变式
- **反查表 18 个条件标签**
